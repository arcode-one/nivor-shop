# NIVØR — Vue 3 storefront

Премиальный интернет-магазин на Vue 3, Vite и Vue Router. Корзина хранится локально в браузере; все страницы и изображения работают без серверной части.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Сборка

```bash
npm run build
```

Готовая статическая версия появится в `dist/`. Сборка оптимизирует изображения и генерирует отдельный HTML для главной, трёх моделей, корзины, оформления и страницы 404. Тексты и метаданные доступны до запуска JavaScript. Создаются `sitemap.xml`, `robots.txt` и `.nojekyll`.

Проверка готовой сборки: `npm run test:seo`. Настройки домена, микроразметки, индексации и действия после публикации описаны в [SEO.md](SEO.md).

## GitHub Pages

Workflow `.github/workflows/deploy.yml` публикует сайт при каждом push в `main` и автоматически подставляет имя репозитория в базовый путь. В настройках репозитория достаточно выбрать **Settings → Pages → Source → GitHub Actions**.

Для проекта с собственным доменом задайте `VITE_BASE_PATH: /` в workflow и добавьте файл `public/CNAME` с доменом.
